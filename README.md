# OmCart — Modern E-Commerce Storefront

OmCart is a responsive e-commerce storefront inspired by large Indian shopping marketplaces. It is an original project and does not use Flipkart branding, assets, or code.

## Features
- Responsive desktop and mobile layout
- Marketplace-style header and search
- Product categories, search, sorting and price filtering
- Product cards with ratings and offers
- Shopping cart with quantity controls and localStorage persistence
- Demo login and checkout interactions
- Deal countdown timer and newsletter interaction

## Tech Stack
HTML5 · CSS3 · Vanilla JavaScript · localStorage · Google Fonts

## Run locally
Open `index.html` in a browser, or serve the repository with any static web server.

## Deployment
Suitable for GitHub Pages, Netlify, Vercel static hosting, or any standard static host.

## Note
This is a front-end demo. Authentication, payments, inventory, orders and checkout are simulated and should be connected to a backend before production use.
